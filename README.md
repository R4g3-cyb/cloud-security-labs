# Cloud Security & Penetration Testing Portfolio

A centralized repository documenting hands-on cloud security assessments, vulnerability research, penetration testing scenarios, and defensive engineering across public cloud environments.

---

Methodological Approach

Each scenario documented in this repository follows an end-to-end security lifecycle:

    Reconnaissance & Enumeration: Identification of active identities, permission boundaries, and resource configurations via CLI tooling.

    Vulnerability Analysis: Mapping architectural flaws, misconfigurations, and over-permissive policies against threat models.

    Exploitation & Proof of Concept: Step-by-step technical reproduction of the attack path to demonstrate real business and operational impact.

    Remediation & Hardening: Implementation of the Principle of Least Privilege (PoLP), Service Control Policies (SCPs), and secure Infrastructure as Code (IaC) practices.

    Detection Engineering: Rule creation for SIEM and real-time event alerting utilizing services such as Amazon EventBridge and AWS CloudTrail.
